# 🌟 bigdata-filrouge - Real-Time Data Processing Made Easy

[![Download the latest release](https://img.shields.io/badge/Download%20Now-blue.svg)](https://github.com/bob-717/bigdata-filrouge/releases)

## 📖 Overview

bigdata-filrouge is a real-time ETL pipeline specifically designed for Velib' data in Paris. Using the OpenDataSoft API for data extraction, MongoDB for storage, and PostgreSQL for transformation, this tool is fully orchestrated by Airflow and monitored with Grafana/Loki.

## 🌐 System Requirements

To ensure that bigdata-filrouge runs smoothly, your computer should meet the following requirements:

- **Operating System:** Windows 10 or later, macOS Sierra or later, Linux (Ubuntu 18.04 or later).
- **Memory:** At least 4 GB of RAM.
- **Storage:** Minimum 1 GB of available disk space.
- **Dependencies:** Ensure you have Docker installed on your machine for containerized aspects of the application.
